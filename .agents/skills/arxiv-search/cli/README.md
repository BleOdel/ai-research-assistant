# arxiv-cli

CLI for searching papers on [arXiv](https://arxiv.org) via its public Export API. No
authentication, zero runtime dependencies — runs with just `bun`.

See [`../SKILL.md`](../SKILL.md) for the full command reference and usage examples.

## Development

```bash
bun install   # dev-only: pulls TypeScript types, no runtime deps
bun run typecheck
bun test
```
